# unslop-claude

An agent skill that makes Claude's prose sound less AI-generated by banning asyndetic parataxis — the rhythmic, verbless fragment style that reads like a slide deck instead of ordinary explanatory writing.

The writing guidance is based on a prompt by John Licato.

## What it does

Once installed, the skill instructs the agent to flag and rewrite patterns such as:

- Verbless noun-phrase sequences: "Three teams, two weeks, one goal."
- Staccato fragments used for emphasis: "No configuration. No delays. No compromises."
- Contrast formulas: "Not X. Not Y. Just Z."
- Conspicuous number rhythms: "12 markets, 4 models, 3 scenarios, one conclusion."

Instead of compressing facts into a rhythmic inventory, the agent restores the connective language (using, across, for each, because, while, with, so that) so that each fact's logical role stays grammatically explicit.

## Install

With the [skills CLI](https://skills.sh):

```sh
npx skills add LordAmit/ailabs --skill unslop-claude
```

Or from a local checkout:

```sh
npx skills add ./unslop-claude-john-licato-prompt
```

## Files

- `SKILL.md` — the skill definition and trigger description that the agent loads.
- `instructions.md` — the full writing guidance, including how to identify the pattern and worked rewrite examples.
